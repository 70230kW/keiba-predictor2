# netkeiba取得方針

確認日: 2026-09-07

## 決定

データ提供元の第一候補をnetkeibaとします。ただし、現在の状態は「採用候補・利用許諾確認中」です。
公開アプリに使える公式APIまたは機械学習用一括CSVは、netkeibaの公式公開情報から確認できていません。
マスターコースは閲覧・分析機能を提供しますが、外部アプリへのデータ供給契約であるとは確認できません。

## 実装しないもの

許諾を確認するまで、以下を実装しません。

- netkeibaページの自動巡回・HTMLスクレイピング
- robots.txt、アクセス制御、レート制限の回避
- 会員ID・パスワード・Cookieの保存やログイン自動化
- netkeibaのデータ、文章、独自指数を公開リポジトリや公開画面へ転載
- VercelまたはGitHub Actionsからの定期アクセス

## 許諾後の接続方法

netkeibaまたは権利者から許諾されたAPI・ファイルが提供された場合だけ、取得元固有のアダプターを追加します。
アダプターは元データを非公開領域で共通CSVへ変換し、現行の `ml.pipeline` に渡します。
オッズ、人気、投票行動、予想印、SNS評価は取得できても予測経路に渡しません。
公開画面には、許諾された範囲の出走情報とモデルの派生結果だけを表示します。

## 確認する質問

netkeiba運営へ以下を確認します。

1. 個人開発の競馬予測モデルの学習に、過去のレース・馬・騎手・コース情報を利用できるか
2. データを自動取得できる正式なAPI、CSV、法人・開発者向け契約があるか
3. 学習済みモデルの予測値を一般公開するWebアプリで利用できるか
4. 元データを非公開で保持する条件、保存期間、更新頻度、表示可能な項目
5. 無料公開、広告掲載、有料化それぞれの許諾・料金・クレジット表記
