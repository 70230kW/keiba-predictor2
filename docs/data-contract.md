# 実データ取込 v0.2

## 今回の範囲
外部通信なしの共通CSV取込・検査・特徴量生成。データ提供元との契約・API連携・スクレイピングは未実施です。
ひな形はサイトからダウンロードできます。画面は引き続き架空サンプルです。
取込は開発環境で実行します。Webへのアップロード、DB永続化、予測自動更新はまだありません。

## 手順
Python 3.10以上。取込・テストは標準ライブラリのみ。
```bash
python -m ml.pipeline /path/to/licensed-results.csv --output data/processed/training.csv
python -m unittest ml.test_pipeline
pip install -r ml/requirements.txt
python -m ml.train
```
既存の出力ファイルは上書きしません。更新時は別の出力パスを指定してください。
実データとモデルはGit管理対象外です。公開リポジトリに提供元のデータや認証情報を載せないでください。

## 入力（UTF-8 / BOM可）
1行は1レースの1頭の確定成績です。列名はひな形と完全一致させます。
- race_date: YYYY-MM-DD、日本時間の開催日
- race_id: ASCII英数字・ハイフン・アンダースコアのレースID
- horse_id: 同じ馬を全レースで識別する不変ID
- distance_m: 距離、400〜5000の整数
- carried_weight: 発走前に判明する斤量、30〜80 kg
- age: 発走時年齢、2〜20の整数
- finish_position: 確定着順、1〜18の整数（目的変数の生成にのみ使用）

欠損、NaN/Infinity、重複、同一馬同日複数出走、レース内の条件矛盾、不明列を拒否します。
取消・除外・競走中止・障害競走・同着は今回の学習対象外です。入力前に除外してください。
完全な出走表であることや着順の整合性は取得元側で確認が必要です。
オッズ・人気などを含む元データはそのまま取り込めません。許可列のみのCSVを作成します。

## 時点と学習境界
特徴量は明示的許可リスト。未知の列も拒否します。
当該レースの着順はモデル入力に含めず、同一馬の「当日より前」の成績のみから出走数・勝率・平均着順・前走間隔を作ります。
過去の成績がない場合は0。prior_startsにより履歴なしと区別できます。
過去履歴が不完全なら特徴量も不完全になります。取込対象期間を記録してください。

日付単位で約60/20/20%に学習・早期終了用検証・最終評価を分割します。
同じ開催日・レースは分割をまたぎません。最終評価期間はモデル選択に使いません。
評価期間内の過去レース結果は、次の開催日には利用可能という逐次予測の前提です。
最低3開催日は動作要件であって精度評価に十分な量ではありません。
LightGBMの生確率は未校正かつレース内合計1を保証しません。表示画面へ直結せず、校正・レース単位評価を次段階で追加します。

## データ取得先の決定に必要な事項
第一候補はnetkeibaです。2026-09-07時点で、公式サイト上に開発者向け公開APIまたは機械学習用CSV提供の案内を確認できていません。
利用規約第14条は、サービスから得たデータを私的利用の範囲を超えて複製・販売・出版したり、不特定または多数が知りうる状態に置いたりするには承認が必要としています。
したがって、書面等で許諾範囲が確認できるまで、自動アクセス、ログイン自動化、HTML取得、Vercelからの定期取得は実装しません。
詳細は [netkeiba取得方針](netkeiba-source.md) を参照してください。
