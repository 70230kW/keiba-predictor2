# JRA-VAN接続方針

確認日: 2026-09-07

## 決定

中央競馬の主要データ取得元としてJRA-VAN Data Lab.を採用します。
公式SDKのJV-Linkを利用し、画面のHTML解析や非公式APIには依存しません。
JV-LinkはWindows PCへインストールして利用するため、Vercelとは取得処理を分離します。

## 構成

1. Windows取得クライアントがJV-Linkから許可されたJV-Dataを取得
2. 元データをWindows側の非公開領域に保存
3. 取得時点を記録し、共通CSV形式へ変換
4. オッズ・人気・投票情報・予想印を予測経路から除外
5. 検査済みデータで学習・予測
6. 公開可能な予測結果だけをVercelアプリへ送信

利用キー、JV-Link設定、元データ、学習済みモデルはGitHubに保存しません。
Windows取得クライアントからクラウドへ送る際は、送信先認証、暗号化、重複防止、再実行可能性を実装します。

## 実装段階

現在は共通CSV取込基盤と取得境界まで実装済みです。
次の段階でJRA-VAN SDKの仕様に基づくWindows取得クライアントを作成します。
実接続にはData Lab.契約、サービスキー、JV-LinkとSDKを導入したWindows環境が必要です。

初期取得対象は、レース情報、出馬情報、確定成績、競走馬・騎手・調教師マスタを予定します。
オッズ系レコードは取得処理の対象外にし、目的変数となる確定着順は学習入力へ混入させません。

## 公開前の確認

JRA-VANの契約・開発ガイドに従い、予測値をWebで公開する場合の表示可能項目、元データの保存、第三者提供、クレジット表記を確認します。
